# prelegal

A platform for drafting common legal agreements.

> **Status:** early development. The repository doesn't contain application code yet. Setup and usage instructions will be added here as the first version takes shape.

## About

prelegal aims to make drafting everyday legal agreements quicker and easier, so people can start from a solid draft instead of a blank page.

## Getting started

There is nothing to install or run yet. Once code is added, this section will cover:

- Prerequisites
- Installation
- Running the project, with examples

To get a copy of the repository:

```bash
git clone https://github.com/Dipanjan95/prelegal.git
cd prelegal
```
